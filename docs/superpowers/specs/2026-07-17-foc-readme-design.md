# FOC 通用使用手册设计

## 目标

在 `foc/README.md` 提供一份面向库使用者和移植者的中文手册，使读者在
不阅读全部实现源码的前提下，能够理解库的分层、完成硬件适配、创建一个或
多个电机实例、配置控制器和观测器，并按正确周期调用控制流程。

README 以通用 MCU 和通用电机控制为主，不把 AT32F413 或 STM32G431 的
厂商接口写进业务示例。现有适配器只作为可参考的实现位置列出。

## 目标读者

- 需要把 FOC 库移植到新 MCU 的嵌入式开发者。
- 需要配置电流、速度或位置闭环的电机控制开发者。
- 需要使用 Hall、SMO、NLFO 或 HFI 的算法开发者。
- 需要在无 FPU 的 Cortex-M0 或 RISC-V MCU 上使用定点后端的开发者。

## 文档组织

README 采用“先跑起来，再查接口”的任务导向结构：

1. 库能力、边界和目录架构。
2. 浮点与 Q16.15 后端选择、归一化量和角度约定。
3. 最小集成流程和初始化顺序。
4. HAL/MDI 适配契约与 `motor_handle_t` 多实例模型。
5. 高频控制周期、低频级联周期和主循环职责。
6. 控制器、调制器和观测器的配置与切换方法。
7. 优化算法与实验算法的使用和安全限制。
8. 多电机、错误处理、参数整定、移植检查和构建测试。
9. 按目录整理的公共接口索引。

## 示例策略

主示例使用硬件无关的 C 代码，展示：

- 选择数值后端。
- 构造带 `pContext` 的 PWM/ADC 接口。
- 初始化 `foc_hal_t` 和 `motor_handle_t`。
- 创建 PID 并通过 `foc_controller_if_t` 绑定。
- 设置电流或速度控制模式。
- 在 PWM/ADC 中断中采样、执行控制并更新占空比。
- 故障时调用紧急停止。

示例只调用仓库中实际存在的公共函数，不虚构便捷封装。为避免误导，硬件
引脚、ADC 触发点、PWM 极性和电流换算系数仅说明责任归属，不写固定值。

## 安全边界

- 明确说明控制输出上电前必须完成电流零偏校准和保护配置。
- NSD 和参数辨识默认关闭，启用时必须提供急停回调及电流、速度、母线电压
  和超时限制。
- HFI、SMO、NLFO、MTPA 和弱磁需要依据实际电机参数整定，README 不提供
  可直接用于未知电机的通用参数。
- 不宣称主机测试或编译验证等价于真实电机验证。

## 接口描述规范

每个主要模块说明以下内容：

- 模块职责及依赖。
- 主要结构体由谁持有，是否包含运行状态。
- 初始化、复位和周期执行函数。
- 输入输出单位、范围和错误返回值。
- 多实例和运行时切换注意事项。

README 不逐行复制头文件，而是提供足够的接口表和指向对应头文件的路径。

## 验收标准

- 所有示例中的类型、字段和函数均能在当前 `foc/` 源码中找到。
- 初始化顺序与真实实现一致。
- 清楚区分高频中断、低频控制和非实时主循环。
- 覆盖浮点、Q16.15、多电机、HAL、控制器、观测器、优化和实验功能。
- 包含 AT32F413 构建及主机测试命令，但不把文档限定为 AT32F413。
- 正文内容完整，不保留占位标记，也不要求业务层包含厂商 HAL 头文件。
