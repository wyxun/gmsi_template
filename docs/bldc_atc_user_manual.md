# AT32F407 控制器 BLDC 主轴机械锁紧式自动换刀 (ATC) 使用手册

本手册介绍基于 AT32F407 控制器的无刷主轴（BLDC Motor）机械螺母卡座式自动换刀系统的配置、参数设定、调试及使用方法。

---

## 1. 系统概述与硬件接线

本系统利用无刷主轴电机具备的低速正/反转控制能力及 FG 转速信号输出，配合固定的机械扳手卡座实现工具的自动拧紧（锁刀）与卸下（松刀）。

### 1.1 硬件引脚映射

| 信号名称 | AT32F407 引脚 | 方向 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **`SPINDLE_PWM`** | **PA6** (TMR3_CH1) | 输出 | 主轴调速 PWM Chopping 信号 (0-100%) |
| **`SPINDLE_DIR`** | **PA5** | 输出 | 主轴转向控制 (LOW=正转/CW, HIGH=反转/CCW) |
| **`SPINDLE_EN`** | **PB0** | 输出 | 主轴使能开关 (HIGH=开启, LOW=关闭) |
| **`SPINDLE_FG`** | **PB1** | 输入 | 主轴 FG 转速脉冲输入 (EXTI1 下降沿中断) |
| **`SPINDLE_ALARM`** | **PC5** | 输入 | 主轴驱动器报警信号输入 (低电平表示报警) |

## 2. 定位原理与坐标计算

自动换刀采用**直排式刀架（Linear Rack）**，所有刀位坐标均在 **G53 机械坐标系**（机器回零后建立的绝对坐标系）下执行，不受工件坐标系（G54/G55等）和刀具长度补偿（G43）影响。

### 2.1 刀位坐标计算公式
系统只需配置 **1号刀座坐标** 及 **刀座间距**，任意第 $N$ 号刀位的坐标由公式自动计算：

$$\text{刀位 } N \text{ 的 X 坐标} = \text{1号刀X坐标 (\$902)} + (N - 1) \times \text{刀座间距 (\$901)}$$
$$\text{刀位 } N \text{ 的 Y 坐标} = \text{1号刀Y坐标 (\$903)}$$

## 3. 参数配置列表 ($900 - $909)

可以通过控制台/串口以 `$90x=值` 的方式实时配置参数，也可以直接在固件头文件中修改初值。

### 3.1 参数详细说明

| 参数编号 | 参数名称 | 单位 | 默认初值 | 取值范围 | 说明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **`$900`** | 刀座总数 | 个 | `8` | 1 ~ 16 | 刀架上一共有几个物理刀位 |
| **`$901`** | 刀座间距 | mm | `50.0` | 1 ~ 500 | 沿 X 轴方向相邻两个刀位的中心距离 |
| **`$902`** | 1号刀 X 轴机械坐标 | mm | `0.0` | ±9999 | 1号刀座中心在 G53 坐标系下的 X 坐标 |
| **`$903`** | 1号刀 Y 轴机械坐标 | mm | `0.0` | ±9999 | 1号刀座在 G53 坐标系下的 Y 坐标 |
| **`$904`** | Z 轴安全避让高度 | mm | `0.0` | ±9999 | 主轴在刀架上方空移避让时的 Z 轴高度 |
| **`$905`** | Z 轴插刀/卡紧深度 | mm | `0.0` | ±9999 | 主轴下降使螺母完全落入卡座时的 Z 轴高度 |
| **`$906`** | 换刀主轴转速 | RPM | `500.0` | 100 ~ 10000 | 松刀与锁刀过程中主轴的旋转转速 |
| **`$907`** | 换刀超时/延时 | ms | `2000` | 100 ~ 30000 | 锁刀/松刀动作的最大限时 |
| **`$908`** | 解扣 FG 脉冲数目标 | 个 | `30` | 1 ~ 1000 | 反转解扣所需旋转的 FG 脉冲目标值 |
| **`$909`** | 换刀选项开关 | 位图 | `1` | 0 ~ 3 | Bit0：FG闭环使能；Bit1：换刀后恢复XY |

## 4. 换刀逻辑选择 (FG 闭环 vs 纯时间延时)

控制模式由 **`$909` 的 Bit 0** 决定：

### 4.1 FG 闭环模式 (`$909 = 1`，推荐)
* **松刀 (Unclamp)**：主轴 CCW 反转，实时统计 EXTI1 中断接收到的 FG 脉冲数。达到目标值 `$908` 时说明锁紧螺母已完全脱扣，自动停转。
* **锁刀 (Clamp)**：主轴 CW 正转锁紧刀柄螺母。当刀柄拧紧受阻时，电机停止旋转不再产生 FG 脉冲。系统检测到 FG 停滞（>300ms 无脉冲且累计脉冲>5）时，判定为已拧紧并自动停转。
* **超时保护**：若动作超过 `$907` ms 未完成，系统自动触发超时保护并停机报警。

### 4.2 纯时间延时模式 (`$909 = 0`)
* 不需要 FG 脉冲反馈。
* 主轴启动后固定运行 `$907` ms，时间到达后直接停止，同时检测驱动器 ALARM 信号。

### 4.3 固件默认初值修改位置
若需在烧录前修改固件内置的默认参数，请修改 [`grblhal_adapt/atc_plugin.h`](file:///d:/1_project/x_cnc/software/grblhal/grblhal_adapt/atc_plugin.h#L47-L56) 中的宏：

```c
/* ---- Default values in atc_plugin.h ---- */
#define ATC_DEFAULT_POCKETS        8
#define ATC_DEFAULT_POCKET_PITCH   50.0f
#define ATC_DEFAULT_RACK_ORIGIN_X  -200.0f  /* 根据实际机械填写 */
#define ATC_DEFAULT_RACK_ORIGIN_Y  -10.0f
#define ATC_DEFAULT_Z_CLEAR        -10.0f
#define ATC_DEFAULT_Z_PICKUP       -85.0f
#define ATC_DEFAULT_SPINDLE_RPM    500.0f
#define ATC_DEFAULT_TIMEOUT_MS     2000
#define ATC_DEFAULT_FG_TARGET      30
```

## 5. 调试与使用操作流程

### 步骤 1：机械回零
在上位机或串口发送 `$H`，完成 Z、X、Y 轴回零，建立基准 G53 机械坐标系。

### 步骤 2：对刀与坐标测定
1. 点动控制主轴移动至 **1号刀座中心正上方**。
2. 记录当前的 G53 X/Y 坐标，分别设置给 `$902` 和 `$903`。
3. 缓慢手动降低 Z 轴，使刀柄螺母卡入机械扳手槽底，记录此时的 G53 Z 坐标，设置给 `$905`。
4. 将 Z 轴抬升至不与刀架碰撞的安全高度，记录 G53 Z 坐标，设置给 `$904`。

### 步骤 3：单步指令独立测试 (mshell 调试)
通过 RTT 调试终端（或控制台）可调用单步测试命令：
* `atc_unclamp`：单独测试反转解扣动作（观察主轴 CCW 旋转及 FG 脉冲计数日志）。
* `atc_clamp`：单独测试正转锁紧动作（观察主轴 CW 旋转及堵转判定日志）。

### 步骤 4：G 代码自动换刀
在 NC 加工程序或串口终端发送以下指令：

```gcode
T2 M6  ; 自动更换为 2号刀
```

#### 自动换刀内部执行步骤：
1. **停止主轴与冷却液**
2. **Z 轴抬升**至安全高度 `$904`
3. **退回旧刀（若主轴上有刀）**：
   - 空移至旧刀座坐标
   - Z 轴下潜至深度 `$905`
   - 主轴反转解扣 (`atc_unclamp`)
   - Z 轴抬升至安全高度 `$904`
4. **获取新刀（若不为 T0）**：
   - 空移至新刀座坐标
   - Z 轴下潜至深度 `$905`
   - 主轴正转锁紧 (`atc_clamp`)
   - Z 轴抬升至安全高度 `$904`
5. **恢复位置**（若选项 `$909` Bit1=1，则自动返回换刀前的 XY 坐标）。

---

## 6. 注意事项

1. **初次测试安全**：建议初次调测试运行不装刀具（空走），并将换刀转速 `$906` 设为较低值（如 `300.0` RPM）。
2. **急停准备**：测试自动换刀时请确保急停按钮处于随时可按下状态。
3. **报警复位**：若出现 `ATC Error` 或主轴 ALARM 报警，系统会中断换刀动作并进入安全停止状态。
